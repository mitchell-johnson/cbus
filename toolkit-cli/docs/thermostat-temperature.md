# Thermostat temperature arithmetic

`cbus_toolkit.thermostat_temperature` implements fourteen original Toolkit
1.18.0.2754 integer conversion functions. Each call requires the exact original
method name, a signed 32-bit integer, and an explicit unit preference:

```python
from cbus_toolkit.thermostat_temperature import METHODS, convert_temperature

convert_temperature('CGateTempToUnitTemp', 0, units='celsius')     # 20
convert_temperature('CGateTempToUnitTemp', 0, units='fahrenheit')  # 68
convert_temperature('UnitTempToCGateTemp', 68, units='fahrenheit') # 0
```

```sh
cbus-toolkit thermostat-temperature methods
cbus-toolkit thermostat-temperature convert CGateTempToUnitTemp 0 --units fahrenheit
cbus-toolkit thermostat-temperature convert QuarterDegreesTempOffsetToCGateTemp 32 --units celsius
```

The CLI returns JSON. `methods` lists the fourteen case-sensitive original
names. Input values are decimal integers; the Python API rejects booleans,
floats and subclasses. Units must be `celsius` or `fahrenheit`. No preference
file, locale, clock, C-Gate connection or device is consulted.

| Original method family | Original behavior preserved |
| --- | --- |
| `SimpleCGateTempToUnitTemp`, `SimpleUnitTempToCGateTemp` | Whole-degree Celsius/Fahrenheit conversion without quarter-degree scaling. |
| `CGateTempToUnitTemp`, `UnitTempToCGateTemp` | Quarter-degree conversion with the original integer offset of 80; reverse conversion clamps results at or below −128 to −127. |
| `CGateTempToWholeDegreesTemp`, `WholeDegreesTempToCGateTemp` | Quarter/whole-degree conversion without the offset. |
| `CGateTempToTempOffset`, `TempOffsetToCGateTemp` | Temperature-difference conversion, without adding 32 for Fahrenheit. |
| `CGateTempToHalfDegreesTempOffset`, `HalfDegreesTempOffsetToCGateTemp` | The original arithmetic is the same as the preceding offset pair; names retain the original wording. |
| `CGateTempToTempOffsetWithShift`, `TempOffsetWithShiftToCGateTemp` | Difference conversion with the original integer shift. |
| `CGate16thDegreeToQuarterDegreeTempOffset`, `QuarterDegreesTempOffsetToCGateTemp` | Original special-quarter formulas, including the stored 1.0241 factor and reverse result limits. |

These functions preserve the original x87 intermediate rounding, helper
double-precision stores and signed integer wrapping. Replacing them with a
single floating-point formula changes boundary results. The implementation uses
exact rational arithmetic and explicit binary rounding, independent of Python's
decimal context. Both original 80-bit constants retain their exact stored bits.

For example, `QuarterDegreesTempOffsetToCGateTemp(32)` with Celsius preference
returns **127**, because the original maps the otherwise computed 128 to 127.
The same function clamps other results to −127 through 255.
`WholeDegreesTempToCGateTemp(1073741824)` with Celsius preference returns **0**
through original Int32 wrapping. These compatibility behaviors are exposed
without interpreting the input as a valid physical thermostat setting.

## Original comparison and limits

[Native Windows evidence](../research/fixtures/thermostat-temperature-native-acceptance.json)
records a 28-case pilot followed by all 1,176 planned cases on the actual
Windows x86 runtime. Every value matched. The harness maps the pinned original
PE image into its own allocation and applies only the executable's standard
HIGHLOW address relocations. It never starts the original application, resolves
imports or constructs a thermostat form. Its wrapper saves and restores caller
integer and x87 state and uses the original `Set8087CW` function.

An earlier fixed-address allocation failed before any original conversion ran.
That failed attempt remains preserved. Before the revised Windows run, the
entire C#-relocated image matched an independent `pefile` reconstruction at four
addresses, and 4,704 emulator cases preserved values and caller state. The
Windows comparator independently reconstructs the relocated baseline and
dynamic wrapper hashes from actual allocation addresses, checks all result
fields and requires every owned resource to release. The image hash describes
the relocated baseline before the declared context-pointer/global writes.

[Portable original vectors](../research/fixtures/thermostat-temperature-vectors.json)
retain those 1,176 native comparisons and a separate 28,840-case original
instruction matrix: fourteen methods, both unit preferences, all integers
−256 through 511, additional signed-boundary neighborhoods and deterministic
32-bit samples. These are captured original results, not values generated by
the Python implementation.

The research helper performs a fresh, confined original-instruction comparison
with all 28,840 rows when `CBUS_TOOLKIT_EXE` points to the exact original
executable. It requires the research dependencies and macOS network denial.
Every reached instruction is checked against the pinned original bytes and
declared ranges. Only stack, wrapper state and the original control-word global
may be written by emulated instructions. The exact loaded Capstone and Unicorn
libraries, source inputs, partial output and final evidence are retained.

This is scalar arithmetic acceptance. Thermostat scheduling, complete form
behavior, project save/load and physical-device operation remain separate
work. The package itself needs only Python's standard library.

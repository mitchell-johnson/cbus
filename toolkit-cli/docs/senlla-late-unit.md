# SENLLA late Unit attributes

`senlla_late_unit.py` extends the concrete inherited owner with live Unit
attributes before PP loading starts. It retains that owner's Unit manager,
application references, blocks and keys, and reads the complete owner's current
parameter journal at each late source position. The source receipt records
numeric method digests and SENLLA virtual-slot targets; it includes no vendor
unit specification or executable instructions.

The NeoPro Join, Corridor, KeyDisable and Nightlight fields begin nil, false or
zero. The complete owner executes their earlier load schedule. Corridor block
references retain native BeforeChange even for equal reference assignments:
reset the old block's TimerMin, then refresh the current block. Active corridor
timers below60 become300 and their minimum becomes60. Both Timer and TimerMin
retain their dedicated minimum-enforcement callbacks on the same block manager.

ST7 loads IR key references, activity bits and indicator ordinal; target and
margin; eight banks Active before Off; scale, maintenance and broadcast;
ascending occupancy masks; PIR group and logic; power states; and potentiometer
function/block references. Maintenance attributes commit the current graph
facts before managed subscribers run. Their native dedicated callbacks remain
nil, so these assignments do not invent an Allowed refresh. Later actual block
publications can still refresh it.

Surface power state and preset setters precede group normalization. A used
target sets target45 and writes margin-group255 into the current PP cache;
the later margin getter reads that cache. A used margin sets margin-percent9.
Each group lookup uses the current application after prior setter callbacks.
Bank low-use, high-use and the final current low-use predicate execute per row;
low lux becomes0 only when the final predicate is true. Use flags retain actual
Boolean attributes and managers, rather than detached final flags.

The live bank adapter owns the same eight bank objects and all current
Active, Allowed, Off, High, Low and use attributes. ST7 and Surface assignments
use their real setters and retained managers, including tracked block changes
and shared stored-byte feedback. Persistent PEC/PIR/surface/bank/global controls
remain under composition. This module does not by itself admit a whole-unit save, public CLI
operation, installed-wheel acceptance, original GUI execution or hardware
acceptance. The authored interaction cases verify this component and its
concrete owned-project dependencies with focused source tests.

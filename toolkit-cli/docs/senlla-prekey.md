## Executor protocol

`source_dispatch(request, engine)` receives the immutable
`SourceLookupRequest` at the current native application/group getter position.
It resolves the actual source manager, performs any creation, metadata naming
and StorageSave work, calls `add_source_application()` or `add_source_group()`
for the source-confirmed canonical identity, and returns `None`. The engine
rereads its canonical map after the executor completes. A registry miss also
dispatches a create=false lookup against the actual manager; it returns nil
only after that source lookup establishes absence. An unavailable executor
refuses instead of treating an unencountered identity as absent. Missing
create=true work requires its actual executor.
Registering an identity is an internal representation step, not acceptance of
native creation or storage. No future final inventory or JSON cache is a
response. An application 255 or group 255 is a real manager-owned object.

The actual GroupManager.Items order is a separate source fact. Registration
order records encountered getters. The owning backend must synchronize native
manager order through the engine's group-order API before later form controls
consume it. This prefix performs identity lookups; it does not claim that
registration order establishes native address/custom-address/TagName sorting.

`inherited_dispatch(request, prekey)` is mandatory. It receives a frozen
`PrekeyOwnerRequest` for base-agent, metadata, Learn and core scalar work and
returns `None` after the actual owning branch and nested callbacks finish.
The Learn request resumes its tail after the already-executed inherited unit
loader; it does not call that full loader again. The tail's native support
predicate still belongs to the inherited executor.
The bound complete raw snapshot is available as `prekey.raw`; current objects
are available as `prekey.runtime`. Its parameter-name list describes the
branch, not an arbitrary writable projection. This preserves the inherited
owner boundary instead of silently treating those branches as no-ops. Authored
test executors exercise callback order without proving a native backend.

The prefix does not load late Neo control/Scene, NeoPro Join/KeyDisable,
ST7 hidden group/occupancy/power, or Surface/fresh form fields. Their getters
must execute later on this same runtime. `snapshot()` returns detached
inspection without native getter notifications. Current eight block levels
must pass through the indexed CoreKey array rebuild before the later ST7
power overlay; LightIndex 3..255 can grow the native array beyond its guarded
ten-byte input and cannot be truncated or reset.

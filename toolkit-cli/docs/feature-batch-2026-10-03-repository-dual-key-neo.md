# Repository capacity, dual-key controls and Neo report profiles

Date: **3 October 2026**. Target: **Toolkit 1.18.0.2754 / C-Gate 3.4.0.2001**.

This batch delivers three bounded functions in parallel: retained large cmqttd
repositories, explicit Timer/Shutter/Room Courtesy callbacks inside one eDLT
parent transaction, and every source-registered Neo/NeoPro project-documentation
class partition. Python `cbus-toolkit` and Rust cmqttd remain separate maintained
products. Full Toolkit/C-Gate parity and broad hardware acceptance remain open.

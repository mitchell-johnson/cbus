later operation. Name validation uses source Trim, UTF-16 entry length,
ASCII-only duplicate comparison and exact Project.TagName exclusion. Existing
long programmatically loaded names can be retained when no operator name is
supplied. Explicit unchanged accepted names are owned no-ops.

The adapter sends source-quoted OID TagName writes, retaining doubled spaces,
NBSP, Unicode, quotes and backslashes. Complete graph/PP freshness and
preservation remain required. Existing used and unrelated Level Value strings
and absence remain opaque; new Level creations retain canonical-byte checks.
Graph-only changes use no PP save. Reviewed actions share one final target
save and close/reload verification. Uncertain writes stop without replay,
inverse rename or later save.

# Owned macOS C-Gate acceptance service

`research/local_cgate.py` starts the original C-Gate 3.4.0 build 2001 JAR in a new temporary state directory using an explicitly selected Java 11 runtime. It adopts no running service or project state. The six command/event/secure listeners must appear under the direct child PID and bind only IPv4 loopback. Plain load/configuration listeners are disabled; original secure listeners are verified individually.

The helper owns reserved sockets, its process, log and working directory. Each reservation is registered immediately. Cleanup makes one termination attempt, escalating to one kill after a bounded wait, and removes the directory only after confirmed process exit. An unconfirmed live process retains its directory without a garbage-collection finalizer. Reports distinguish process exit, reservation/log closure, directory removal and cleanup errors. Startup/body exceptions survive cleanup failures and interruptions. Reports include only allowlisted startup log lines and hashes, excluding arbitrary log content and generated key material.

All 16 tests passed with no skips on Python 3.13 (1.082 s) and 3.10 (1.263 s). Fifteen fault tests cover startup, port allocation, ownership, timing and cleanup interruptions. The native test independently checks six listeners, an initially empty project list, a disposable project lifecycle and final process/directory removal. It never opens a C-Bus network. Compact source/report hashes are in `research/fixtures/local-native-oracle-acceptance.json`; full local reports remain under `research/runtime/cgate-macos-owned/local-helper-*.json`.

Run the native test with `CBUS_CGATE_JAVA` pointing to the task-owned portable Java executable and `CBUS_LOCAL_CGATE_VENDOR` pointing to the original C-Gate app directory. `CBUS_LOCAL_CGATE_REPORT` optionally selects a report path. No runtime is installed globally. This is research service infrastructure, not Toolkit parity or physical hardware acceptance. Process launch, operating-system inspection and cleanup do not provide a real-time deadline guarantee.

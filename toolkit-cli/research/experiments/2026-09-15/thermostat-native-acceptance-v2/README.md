# Native scheduling acceptance source snapshot

The archived driver produced the focused 67-test result on Python 3.13.14 and 3.10.20. Exact source and runtime inputs were archived before execution; the [compact acceptance fixture](../../../fixtures/thermostat-schedule-native-acceptance.json) pins both reports, the archive and native cleanup evidence. Five native integration methods cover eight project/group scenarios per run. Fourteen captured original outcomes are replayed; this driver does not execute original Toolkit instructions.

These are byte-identical authored sources from the recorded external paths, not a portable automatic runner. They require explicitly selected native runtimes, isolated storage, an existing input manifest and new output paths. Proprietary binaries and large raw outputs are excluded. Earlier failed attempts remain preserved externally. The [product guide](../../../../docs/native-thermostat-schedule.md) describes the accepted CLI and remaining scope.

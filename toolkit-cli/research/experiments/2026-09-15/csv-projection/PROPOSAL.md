# Cached CSV projection pilot: twelve original-instruction cases

Status: prepared for independent review; no original projection execution admitted.

This extends the accepted row serializer with actual original TFlashUnitBuilder.CreateFlashObject, TUnitTypeFactory.GetUnit, FirmwareWithinLimits/VersionStringCompare, the selected generic/TRELAY4 VMT getters, original StorageLoad/StorageSave dispatch, original missing-group allocation branch, and original AsCSV. It deliberately does not claim full XML loading, full unit/group constructors, installed factory registration, Delphi heap/reference-counting, original storage backends or whole Toolkit startup.

The original RELAY4 registration is pinned to the exact initialization source: class TRELAY4, type RELAY4, lower0, upper9. The owned factory contains only that registration, with its actual class pointer. The unchanged original builder reads UNITTYPE and FIRMWAREVERSION from an explicit TFlashCachedObject fixture. The original factory decides its selected constructor. A strict constructor-return provider supplies one initialized owned unit, checking class/workspace/arguments/callsite, and uses that actual original class VMT. The generic fallback's SetUnitType is allowed to execute unchanged. This is a class-dispatch test over explicit cached facts, not an arbitrary XML-to-object parser.

Cases cover unknown generic, normal relay, lowercase/lower bound, upper bound, integer and dotted upper failures, two sequential supplied QuickGet values, invalid Area default255, original missing255 group creation with GroupSave, definite denied save after creation, omitted Area column, and denied first QuickGet. All cases carry eight ordered unit groups, exposing the relay rule index<max(4,6), while generic uses its original all-interaction rule.

Each case runs in fresh emulator memory. The phases are supplied cache setup, original factory call, source snapshot, original AsCSV, and terminal snapshot. No diagnostic Area getter is called before or after the serializer. AsCSV unconditionally calls Area before column-mask rendering and calls it again when its first result is nonnil. Therefore omitted Area columns still perform two supplied loads, and the second supplied value may determine the exported label. Each entry/return and storage operation is recorded without invoking another getter.

StorageLoad uses a preattached retained owned agent; only the exact QuickGet/Parameter=AreaGroupAddress request for this unit is allowed. The provider supplies the ordered raw Area strings, recording before/after. Missing255 follows original GroupByAddress/Add/SetAddress and <Unused> tag assignment, through supplied constructor, collection and attribute primitives; original StorageSave must request exactly GroupSave for the newly created group. That provider records the supplied save or raises a declared stop. A denied save is a partial export with the already-created group retained in evidence; it is never a completed or successful save.

Application/Area reference getters use original initialized/resolved reference methods. Reference assignment preserves the original method writes and explicitly supplied empty-workspace-name/OID/reference-list primitives; event publishers and entity managers are absent from this declared fixture. Owned primitive callbacks and all original methods must be listed and audited separately. No broad read-only metadata or full reference-notification claim follows from this setup.

Every executed original instruction must be predecoded from the exact EXE/MAP, byte-checked at execution, and included in the source manifest. PE text remains read-only. Only a declared singleton data pointer is supplied by the fixture before execution and then protected; guest writes are restricted to owned heap/stack and its SEH word. All imported/native/exception/unknown callbacks stop immediately. Input, heap, instruction, callback, output and whole-process bounds apply. No VM, C-Gate, real project, registry or network call is permitted.

The report keeps input/raw string order, selected class and all constructor flags, cached groups/addresses/OIDs/reference identities, raw Area changes, requested metadata creation/save, original instructions/provider calls, emitted CSV lines and exact original/loaded emulation-library/source hashes. Capture-complete and every-operation-success are separate. Expected class, load/creation/save counts and literal final rows are fixed before execution. Any unexpected original or harness path stops the pilot, preserves first error plus partial output, and requires review before a new version; no silent provider broadening/replay.

## Final review/launch boundary

`NativeCachedCSVProbe.py prepare NEW_CHILD` only decodes and checks the original instruction map; it never creates a Machine or calls emu_start. Early preparation failures and each matching source version are preserved. The normal Delphi finally-continuation rule admits only a within-method immediate pushed immediately after the exact `mov fs:[eax],edx` restoration bytes; invalid-cast and exception dispatcher targets remain excluded. The declared target and original bytes are recorded and required normal terminal addresses are asserted.

`run.py NEW_CHILD` remains held by an absent `admission.json`. After review it will require the exact source/case hashes and authorization token, archive and reread all original/source/runtime inputs before launching, use the already accepted file-backed CSV process launcher under macOS `deny network*`, and retain every subprocess stdout/stderr/attempt/started/reaped field. Loaded Capstone/Unicorn library hashes must equal the accepted CSV library pins. All source, Python library files and native libraries are rehashed afterward. The probe cannot claim a capture if its own postchecks fail. All static extraction directories and preparation attempts remain historical research; no original case has executed during preparation.

The fixture's group reference lists, empty workspace name, OIDs, initialized attributes without publishers/entity managers, and preattached retained storage agents are supplied explicitly. Original reference getter/setter code performs the observed pointer/token/workspace/session and attribute updates; no general notifications or real storage backend behavior is inferred. Generic fixtures have no relay Area attribute injected into their class layout.

The supplied cached-string primitives follow the constructor/AddAttribute source: the names TStringList is sorted `[FIRMWAREVERSION, UNITTYPE]`, and its Objects map to inserted value indices `[1,0]`; the value list retains inserted `[UNITTYPE,FIRMWAREVERSION]`. All names and numeric value indices are recorded. These primitive lists are supplied, not a claim that the original XML loader or TStringList constructor has executed.

Both probe and launcher require Python3.10 or3.13. On success or failure they make guarded host-only source/runtime posthash attempts, recording each failure while retaining the first exception. Launcher failure evidence includes the hash/size and available error/completion fields of a partial canonical or pending child report, even after nonzero child exit. Failed postchecks never set passed/capture-complete true.

Final input and output admission: both launch and probe read bounded regular files through nonblocking, no-follow descriptors; the same admitted helper bytes are compiled for loading. A read/validation interruption remains primary if descriptor close also fails. The standalone probe rejects a symlinked capture parent and checks resolved prospective containment before creating its output. These guard checks are host-only and do not execute original methods.
